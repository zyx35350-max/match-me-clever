# Career Compass AI

Create a working personal AI job search assistant for me, not a general job board or marketing landing page, focused on AI matching and recommendations with clear explanations of why jobs fit. Build it for my personal use, not for employers, not for recruiters. Use mock job data first so the full flow works end to end, with these pages: a dashboard, an editable personal profile, AI career matching, a today match jobs view, job details, saved jobs, and an activity or application log. The design should feel clean, professional, with plenty of white space, more like a product tool than a flashy marketing site. Connect to real job data sources later, but prioritize getting the matching logic and user flow working first.
